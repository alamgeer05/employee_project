-----------------------------------
    try / except / else / finally

There are four parts:

try:
    # code that might fail

except:
    # runs if error occurs

else:
    # runs if NO error occurs

finally:
    # runs whether error happens or not




raise vs return

This is VERY important.

return
return {"message": "Employee found"}

means:

Everything is fine. Send a successful response.

raise
raise HTTPException(
    status_code=404,
    detail="Employee not found"
)

means:

Something went wrong. Stop this function and return an error.





---------------------------------------
Your first rule

For now, remember only this:

from fastapi import HTTPException

raise HTTPException(
    status_code=404,
    detail="Employee not found"
)

HTTPException = tell FastAPI to stop normal execution and return an HTTP error response.




-------------------------------------------
One important improvement to your project

Instead of writing:

raise HTTPException(
    status_code=404,
    detail="Employee not found"
)

you can use FastAPI's status constants:

from fastapi import HTTPException, status

Then:

raise HTTPException(
    status_code=status.HTTP_404_NOT_FOUND,
    detail="Employee not found"
)

It's more readable.
